# Ardoise 0.1.0

*First release* · 2026-10-19

Ardoise is a dark theme and a set of reusable components for Qt 6 Widgets desktop
applications on Linux, macOS and Windows.

## Highlights

- **One-call theme**: `Ardoise::Theme::apply()` installs a Fusion-based style, palette,
  typography and translations; every standard Qt control is styled without style sheets.
- **Components**: `PrimaryButton`, `IconButton`, `SearchField`, `PlainTextEdit` with an
  advisory counter, `CollapsibleSection`, `TreeView`, `ThumbnailView` and
  `ThumbnailDelegate`, `Panel`, and `MainWindow` and `Dialog` shells with native title bars.
- **Icons**: 40 monochrome SVG icons in four tones through `IconProvider`.
- **Design tokens**: colors, spacing, radii, control heights and typography through
  `Theme::tokens()`.
- **Translations**: English and French text for the components.
- **Integration**: `FetchContent`, `add_subdirectory()` or a relocatable installed package,
  all through the `Ardoise::Widgets` target.

## Requirements

CMake 3.21+, a C++20 compiler and Qt 6.2+ with Widgets, SVG and LinguistTools.

## Notes

The API may change between minor versions before 1.0. Linux is validated by automated
offscreen tests; macOS and Windows are built and tested in CI, and native window
behavior on those systems still needs checks on real desktops.
