# Consumer example

This console example includes a public Ardoise header and a Qt Widgets header,
links only `Ardoise::Widgets`, and prints the compiled library version. It creates
no visible window and runs with the offscreen Qt platform.

Standalone builds compile it by default. It can also be configured
independently using a source checkout or an installed `Ardoise` package. See
[CONTRIBUTING](../../CONTRIBUTING.md) for both workflows.
